📖 Dicionário do Dev

Glossário Dev

Aquele termo que todo mundo usa e ninguém explica? Está aqui. Pesquise ou filtre por categoria.

API Web

Application Programming Interface. Um "contrato" que permite dois sistemas conversarem. Ex: seu site pede dados a um servidor via API e recebe JSON de volta.

DOM Front-end

Document Object Model. A representação em árvore da página que o JavaScript manipula para mudar textos, estilos e elementos.

HTTP Web

Protocolo que define como navegador e servidor trocam mensagens (requisições e respostas) na web.

JSON Web

JavaScript Object Notation. Formato leve de texto para trocar dados entre sistemas. Ex: { "nome": "Ana" }.

CRUD Back-end

Create, Read, Update, Delete — as quatro operações básicas sobre dados. A base de quase todo sistema.

Responsivo Front-end

Layout que se adapta a qualquer tamanho de tela (celular, tablet, desktop), geralmente com Media Queries em CSS.

Framework Front-end

Conjunto de ferramentas e regras que acelera o desenvolvimento. Ex: React e Vue para interfaces.

Componente Front-end

Pedaço reutilizável e independente de interface (ex: um botão ou um card) que pode ser combinado para formar telas.

Backend Back-end

O "lado servidor" da aplicação: lógica de negócio, banco de dados e APIs. Não é visível diretamente pelo usuário.

PostgreSQL Back-end

Banco de dados relacional open source. Você conversa com ele usando SQL (Structured Query Language), a linguagem para consultar e manipular dados em tabelas.

Git Ferramentas

Sistema de controle de versão: guarda o histórico do seu código e permite trabalhar em equipe sem sobrescrever o trabalho alheio.

npm Ferramentas

Node Package Manager. Gerenciador de pacotes do Node.js, usado para instalar bibliotecas e rodar scripts do projeto.

CLI Ferramentas

Command Line Interface. Interface de texto onde você digita comandos — o terminal. Rápida e poderosa.

TypeScript Front-end

Superset do JavaScript que adiciona tipagem estática, ajudando a pegar erros antes mesmo de rodar o código.

localStorage Web

Armazenamento do navegador que guarda dados (como texto) mesmo após fechar a página. Útil para preferências e estado simples.

Promise Front-end

Objeto que representa um valor que estará disponível no futuro — a base do código assíncrono em JavaScript.

Endpoint Web

Uma URL específica de uma API que responde a um pedido. Ex: /api/usuarios retorna a lista de usuários.

Deploy Ferramentas

Publicar a aplicação em um servidor para que fique acessível na internet (ex: Vercel, Netlify, Render).

Acessibilidade (a11y) Front-end

Prática de tornar sites usáveis por todas as pessoas, incluindo quem usa leitores de tela ou navega só pelo teclado.

REST Back-end

Estilo de arquitetura para APIs que usa os métodos HTTP (GET, POST, PUT, DELETE) sobre recursos identificados por URLs.
