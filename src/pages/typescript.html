🔷 JavaScript com superpoderes

TypeScript

TypeScript é JavaScript com tipagem estática. Você escreve quase o mesmo código, mas o compilador avisa sobre erros antes de rodar — menos bugs, mais autocomplete, código mais fácil de manter.

🤔

Por que usar TypeScript?

Em JS, "5" * 2 dá 10 mas "5" + 2 dá "52" — e você só descobre rodando. O TS pega esse tipo de confusão na hora de escrever. É padrão em React, Angular, Vue e back-end com Node.

⚙️
Como rodar Instale com npm install -g typescript e compile com tsc arquivo.ts. O resultado é um .js que roda em qualquer lugar. Veja mais em Terminal & npm.

🏷️ Tipos básicos

Anote o tipo depois do nome, com dois-pontos.

TypeScript 
let nome: string = "Ana";
let idade: number = 30;
let ativo: boolean = true;
let tags: string[] = ["dev", "web"];   // array de strings
let par: [string, number] = ["x", 10]; // tupla

// 'any' desliga a checagem — evite!
let qualquer: any = "pode virar qualquer coisa";

📐 Interfaces & types

Descrevem a "forma" de um objeto — um contrato que o TS verifica.

TypeScript 
interface Usuario {
  nome: string;
  idade: number;
  email?: string; // o '?' torna opcional
}

const u: Usuario = { nome: "Ana", idade: 30 };

// 'type' faz algo parecido e ainda cria uniões:
type Status = "ativo" | "inativo" | "banido";
let s: Status = "ativo"; // só aceita esses 3 valores

🔧 Funções tipadas

Tipe os parâmetros e o retorno para evitar surpresas.

TypeScript 
function somar(a: number, b: number): number {
  return a + b;
}

somar(2, 3);     // ✅ 5
somar(2, "3");   // ❌ Erro detectado pelo TS!

// Arrow function com retorno void (não retorna nada)
const log = (msg: string): void => console.log(msg);

🎁 Generics

"Tipos parametrizados": funções/estruturas que funcionam com qualquer tipo mantendo a segurança.

TypeScript 
function primeiro<T>(lista: T[]): T {
  return lista[0];
}

primeiro<number>([1, 2, 3]); // retorna number
primeiro(["a", "b"]);          // TS infere string

🔎 Narrowing (estreitar tipos)

Quando um valor pode ser de vários tipos, o TS "entende" o tipo dentro de cada if.

TypeScript 
function formatar(valor: string | number) {
  if (typeof valor === "string") {
    return valor.toUpperCase(); // aqui o TS sabe que é string
  }
  return valor.toFixed(2);       // aqui sabe que é number
}

🔢 Enums

Um conjunto de valores nomeados — bom para status, papéis, direções.

TypeScript 
enum Papel {
  Admin = "ADMIN",
  Editor = "EDITOR",
  Leitor = "LEITOR",
}

let meuPapel: Papel = Papel.Admin;
console.log(meuPapel); // "ADMIN"

🏛️ Classes tipadas

TS adiciona modificadores (public, private, readonly) às classes do JS.

TypeScript 
class Conta {
  private saldo = 0;                 // só acessível dentro da classe
  constructor(public dono: string) {} // atalho: cria e atribui

  depositar(valor: number): void {
    this.saldo += valor;
  }
  get total(): number {
    return this.saldo;
  }
}

const c = new Conta("Ana");
c.depositar(100);
console.log(c.total); // 100

🛠️ Utility Types

Tipos prontos que transformam outros tipos — economizam muito código.

TypeScript 
interface Usuario { id: number; nome: string; email: string; }

Partial<Usuario>            // todos os campos opcionais
Required<Usuario>           // todos obrigatórios
Pick<Usuario, "id" | "nome"> // só id e nome
Omit<Usuario, "email">       // tudo menos email
Readonly<Usuario>            // não pode alterar
💡
Caso real Ao atualizar um usuário você quase nunca manda todos os campos — Partial<Usuario> descreve exatamente "alguns campos do usuário".

✅ Faça

// Tipos explícitos em APIs públicas
function getUser(id: number): Usuario { ... }

// Use union types em vez de any
let id: number | string;

❌ Evite

// 'any' espalhado mata a vantagem do TS
let dados: any;

// Ignorar erros do compilador
// @ts-ignore
