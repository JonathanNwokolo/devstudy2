Vue.js

O Framework Progressivo

Vue.js é um framework JavaScript progressivo para construir interfaces de usuário, focado em ser acessível, versátil e performático.

🎯

Fácil de Aprender

Vue.js tem uma curva de aprendizado suave. Se você conhece HTML, CSS e JavaScript, já está pronto para começar!

🔧

Versátil

Pode ser integrado incrementalmente em projetos existentes ou usado como um framework completo para SPAs.

⚡

Reatividade Poderosa

Sistema de reatividade refinado que rastreia dependências automaticamente e atualiza o DOM de forma eficiente.

📦

Single File Components

Arquivos .vue encapsulam template, lógica e estilos em um único lugar, facilitando a organização.

Fundamentos

Conceitos Essenciais do Vue.js

Domine os conceitos fundamentais para começar a desenvolver com Vue.js.

📝

Templates Declarativos

Vue.js usa templates baseados em HTML que são compilados em funções de renderização otimizadas do Virtual DOM. 

<template>
  <div>
    <p>{{ mensagem }}</p>
    <p>{{ mensagem.toUpperCase() }}</p>
  </div>
</template>
🔄

Data e Reatividade

A função data() retorna um objeto reativo. Quando os dados mudam, a view é atualizada automaticamente. 

export default {
  data() {
    return {
      mensagem: 'Olá Vue!',
      contador: 0,
      itens: ['A', 'B', 'C']
    }
  }
}
🎯

Diretivas

Diretivas são atributos especiais com o prefixo v- que aplicam comportamento reativo ao DOM. 

<!-- v-if: renderização condicional -->
<p v-if="mostrar">Visível</p>

<!-- v-for: renderização de listas -->
<li v-for="item in itens" :key="item">
  {{ item }}
</li>

<!-- v-model: two-way binding -->
<input v-model="mensagem" />
⚙️

Methods

Métodos são funções definidas no componente que podem ser chamadas em eventos ou em outros métodos. 

export default {
  data() {
    return { count: 0 }
  },
  methods: {
    incrementar() {
      this.count++
    },
    resetar() {
      this.count = 0
    }
  }
}
🧮

Computed Properties

Propriedades computadas são valores derivados que são cacheados e recalculados apenas quando suas dependências mudam. 

export default {
  data() {
    return {
      nome: 'João',
      sobrenome: 'Silva'
    }
  },
  computed: {
    nomeCompleto() {
      return `${this.nome} ${this.sobrenome}`
    }
  }
}
👆

Manipulação de Eventos

Use a diretiva v-on (ou @) para escutar eventos do DOM e executar JavaScript quando eles ocorrem. 

<template>
  <!-- Sintaxe longa -->
  <button v-on:click="incrementar">+1</button>
  
  <!-- Sintaxe curta (recomendada) -->
  <button @click="incrementar">+1</button>
  
  <!-- Com modificadores -->
  <form @submit.prevent="onSubmit">
    ...
  </form>
</template>
Vue 3

Composition API

A Composition API do Vue 3 oferece uma forma mais flexível de organizar a lógica dos componentes.

📦 Setup Function

A função setup() é o ponto de entrada para usar a Composition API. 

import { ref } from 'vue'

export default {
  setup() {
    const count = ref(0)
    
    return { count }
  }
}

🔗 ref e reactive

ref() cria uma referência reativa, reactive() torna objetos reativos. 

import { ref, reactive } from 'vue'

const count = ref(0)
const state = reactive({
  nome: 'Vue'
})

🧮 computed

Cria valores computados reativos baseados em outras referências. 

import { ref, computed } from 'vue'

const count = ref(0)
const dobro = computed(() => 
  count.value * 2
)

👀 watch e watchEffect

Observa mudanças em dados reativos e executa efeitos colaterais. 

import { watch, ref } from 'vue'

const count = ref(0)
watch(count, (newVal) => {
  console.log(newVal)
})

🪝 Lifecycle Hooks

Hooks de ciclo de vida para a Composition API.

import { onMounted, onUnmounted } from 'vue'

onMounted(() => {
  console.log('Montado!')
})

📦 Composables

Funções reutilizáveis que encapsulam lógica com estado reativo. 

function useMouse() {
  const x = ref(0)
  const y = ref(0)
  // lógica...
  return { x, y }
}
Ciclo de Vida

Lifecycle Hooks

Hooks de ciclo de vida permitem executar código em diferentes estágios do componente.

🎬

Options API - Lifecycle

Hooks de ciclo de vida na Options API.

export default {
  data() {
    return { mensagem: 'Olá' }
  },
  
  // Antes de criar
  beforeCreate() {
    console.log('Antes de criar');
  },
  
  // Depois de criar
  created() {
    console.log('Criado!');
    // Ideal para fazer requisições
  },
  
  // Depois de montar no DOM
  mounted() {
    console.log('Montado!');
    // DOM está disponível
  },
  
  // Antes de desmontar
  beforeUnmount() {
    console.log('Desmontando...');
    // Limpar timers, listeners
  }
}
⚡

Composition API - Lifecycle

Hooks de ciclo de vida na Composition API.

import { 
  onBeforeMount,
  onMounted,
  onBeforeUpdate,
  onUpdated,
  onBeforeUnmount,
  onUnmounted
} from 'vue'

export default {
  setup() {
    onMounted(() => {
      console.log('Componente montado');
    });
    
    onUpdated(() => {
      console.log('Componente atualizado');
    });
    
    onUnmounted(() => {
      console.log('Componente desmontado');
    });
  }
}
🔄

Exemplo Prático

Usando lifecycle hooks para gerenciar recursos.

import { onMounted, onUnmounted, ref } from 'vue'

export default {
  setup() {
    const timer = ref(0);
    let interval;
    
    onMounted(() => {
      interval = setInterval(() => {
        timer.value++;
      }, 1000);
    });
    
    onUnmounted(() => {
      clearInterval(interval);
    });
    
    return { timer };
  }
}
Componentes

Comunicação entre Componentes

Props, emits, slots e provide/inject para comunicação entre componentes.

📤 Props e Emits

Comunicação pai → filho (props) e filho → pai (emits).

<!-- Componente Filho -->
<script>
export default {
  props: {
    titulo: String,
    ativo: Boolean
  },
  emits: ['atualizar'],
  methods: {
    handleClick() {
      this.$emit('atualizar', 'dados');
    }
  }
}
</script>

<!-- Componente Pai -->
<Filho 
  :titulo="meuTitulo"
  @atualizar="handleUpdate"
/>

🎰 Slots

Passe conteúdo para componentes filhos.

<!-- Componente Card -->
<template>
  <div class="card">
    <header>
      <slot name="header"></slot>
    </header>
    <main>
      <slot></slot> <!-- default slot -->
    </main>
  </div>
</template>

<!-- Uso -->
<Card>
  <template #header>
    <h1>Título</h1>
  </template>
  <p>Conteúdo do card</p>
</Card>

💉 Provide / Inject

Compartilhe dados entre componentes sem prop drilling.

// Componente Pai
import { provide, ref } from 'vue'

setup() {
  const tema = ref('dark');
  provide('tema', tema);
}

// Componente Filho (qualquer nível)
import { inject } from 'vue'

setup() {
  const tema = inject('tema');
  return { tema };
}

🎭 Scoped Slots

Slots com acesso aos dados do componente filho.

<!-- Componente Lista -->
<template>
  <div v-for="item in items">
    <slot :item="item"></slot>
  </div>
</template>

<!-- Uso -->
<Lista :items="produtos">
  <template #default="{item}">
    <h3>{{ item.nome }}</h3>
    <p>{{ item.preco }}</p>
  </template>
</Lista>

Configuração de Rotas

import { createRouter, createWebHistory } from 'vue-router'
import Home from './views/Home.vue'

const routes = [
  { path: '/', component: Home },

🎯

Parâmetros de Rota

import { useRoute } from 'vue-router'

setup() {
  const route = useRoute();
  
  // Parâmetros da URL: /usuario/123
  const userId = route.params.id;
  
  // Query params: ?nome=joao
  const nome = route.query.nome;
  
  return { userId, nome };
}
Estado Global

Pinia - Gerenciamento de Estado

Pinia é a solução oficial de gerenciamento de estado para Vue 3.

🍍 Criar Store

Defina stores com state, getters e actions.

import { defineStore } from 'pinia'

export const useUserStore = defineStore('user', {
  state: () => ({
    nome: '',
    email: '',
    logado: false
  }),
  
  getters: {
    nomeCompleto(state) {
      return `Sr. ${state.nome}`;
    }
  },
  
  actions: {
    async login(email, senha) {
      // lógica de login
      this.logado = true;
    }
  }
});

🎯 Usar Store

Acesse o estado da store em componentes.

import { useUserStore } from './stores/user'

setup() {
  const userStore = useUserStore();
  
  // Acessar state
  console.log(userStore.nome);
  
  // Acessar getters
  console.log(userStore.nomeCompleto);
  
  // Chamar actions
  userStore.login('user@email.com', '123');
  
  return { userStore };
}

🔄 Store com Composition API

Sintaxe alternativa usando setup().

import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useCounterStore = defineStore('counter', () => {
  const count = ref(0);
  
  const dobro = computed(() => count.value * 2);
  
  function incrementar() {
    count.value++;
  }
  
  return { count, dobro, incrementar };
});

📦 Persistência

Persista o estado da store no localStorage.

import { defineStore } from 'pinia'

export const useCartStore = defineStore('cart', {
  state: () => ({
    items: []
  }),
  
  persist: true // Com plugin pinia-plugin-persistedstate
});
Forms

Trabalhando com Formulários

Two-way binding, validação e manipulação de formulários no Vue.

🔗

v-model - Two-Way Binding

<template>
  <form @submit.prevent="handleSubmit">
    <!-- Input text -->
    <input v-model="nome" placeholder="Nome" />
    
    <!-- Checkbox -->
    <input type="checkbox" v-model="aceito" />
    
    <!-- Select -->
    <select v-model="pais">
      <option>Brasil</option>
      <option>Portugal</option>
    </select>
    
    <button>Enviar</button>
  </form>
</template>

<script>
export default {
  data() {
    return {
      nome: '',
      aceito: false,
      pais: 'Brasil'
    }
  }
}
</script>
⚙️

Modificadores v-model

<template>
  <!-- .lazy - atualiza no blur -->
  <input v-model.lazy="mensagem" />
  
  <!-- .number - converte para número -->
  <input v-model.number="idade" type="number" />
  
  <!-- .trim - remove espaços -->
  <input v-model.trim="nome" />
</template>
✅

Validação de Formulário

<script setup>
import { ref, computed } from 'vue'

const email = ref('');
const senha = ref('');

const emailValido = computed(() => {
  const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  return regex.test(email.value);
});

const senhaSegura = computed(() => {
  return senha.value.length >= 8;
});

const formValido = computed(() => {
  return emailValido.value && senhaSegura.value;
});
</script>

<template>
  <input v-model="email" />
  <span v-if="!emailValido">Email inválido</span>
  
  <button :disabled="!formValido">Enviar</button>
</template>
Diretivas

Diretivas Personalizadas

Crie diretivas customizadas para manipular o DOM diretamente.

🎯 Diretiva Global

// main.js
const app = createApp(App);

app.directive('focus', {
  mounted(el) {
    el.focus();
  }
});

// Uso
<input v-focus />

📱 Diretiva Local

<script>
export default {
  directives: {
    cor: {
      mounted(el, binding) {
        el.style.color = binding.value;
      },
      updated(el, binding) {
        el.style.color = binding.value;
      }
    }
  }
}
</script>

<!-- Uso -->
<p v-cor="'red'">Texto vermelho</p>

👁️ Diretiva de Visibilidade

app.directive('visible', {
  beforeMount(el, binding) {
    el.style.display = binding.value ? '' : 'none';
  },
  updated(el, binding) {
    el.style.display = binding.value ? '' : 'none';
  }
});

<!-- Uso -->
<div v-visible="mostrar">Conteúdo</div>

🖱️ Diretiva de Click Outside

app.directive('click-outside', {
  mounted(el, binding) {
    el.clickOutsideEvent = function(event) {
      if (!(el === event.target || el.contains(event.target))) {
        binding.value(event);
      }
    };
    document.addEventListener('click', el.clickOutsideEvent);
  },
  unmounted(el) {
    document.removeEventListener('click', el.clickOutsideEvent);
  }
});
Dicas

Boas Práticas Vue.js

Convenções e padrões recomendados pela comunidade Vue.

📁

Estrutura de Projeto

Organize arquivos por funcionalidade e mantenha componentes .vue coesos. 

src/
  components/
    UserList.vue
    UserCard.vue
  views/
    Home.vue
    About.vue
  composables/
    useUser.js
  stores/
    user.js
  router/
    index.js
🏷️

Nomenclatura de Componentes

Use PascalCase para componentes e kebab-case em templates.

// ✅ Bom
// UserProfile.vue
<user-profile />
<UserProfile />

// ❌ Evite
// userprofile.vue
// User_Profile.vue
🎯

Prop Validation

Sempre valide props com tipos e required.

// ✅ Bom
props: {
  titulo: {
    type: String,
    required: true
  },
  idade: {
    type: Number,
    default: 0,
    validator(value) {
      return value >= 0;
    }
  }
}
🔑

Keys em v-for

Sempre use :key com valores únicos em v-for.

<!-- ✅ Bom -->
<div 
  v-for="item in items"
  :key="item.id"
>
  {{ item.nome }}
</div>

<!-- ❌ Evite -->
<div v-for="(item, index) in items" :key="index">
⚡

Computed vs Methods

Use computed para valores derivados, methods para ações.

// ✅ Use computed para cálculos
computed: {
  total() {
    return this.preco * this.quantidade;
  }
}

// ✅ Use methods para ações
methods: {
  adicionarCarrinho() {
    // ação
  }
}
🧩

Componentes Pequenos

Divida componentes grandes em componentes menores e focados. 

<!-- Ao invés de -->
<template>
  <div>
    <!-- 500 linhas de código -->
  </div>
</template>

<!-- Divida em -->
<Header />
<MainContent />
<Footer />
