🗺️ Por onde começar

Trilha de Aprendizado

Não sabe a ordem certa para estudar? Siga esta trilha, dos fundamentos até frameworks e back-end. Cada etapa traz o que aprender e links diretos para o conteúdo aqui no DevStudy.

1
Fundamentos

🏗️ HTML — a estrutura

Aprenda a estruturar páginas: tags, semântica, listas, imagens, links e formulários. É o esqueleto de tudo na web.

Estudar HTML + Acessibilidade
2
Fundamentos

🎨 CSS — o visual

Cores, tipografia, Box Model, Flexbox, Grid e responsividade. Transforme a estrutura em algo bonito e que funciona em qualquer tela.

Estudar CSS Flexbox Responsivo
3
Ferramentas

⌨️ Terminal & Git

Aprenda a usar a linha de comando e a versionar seu código. Git é obrigatório em qualquer trabalho de programação.

Terminal & npm Git & GitHub
4
Lógica

⚡ JavaScript — a interatividade

Variáveis, funções, arrays, objetos, DOM e assíncrono. É aqui que sua página ganha vida e lógica.

Estudar JavaScript
5
Integração

🌐 APIs, Fetch & HTTP

Entenda como o front conversa com servidores: requisições, JSON, status codes e async/await na prática.

APIs & Fetch HTTP Status
6
Escala

🔷 TypeScript

Adicione tipagem ao JavaScript para evitar bugs e escrever código mais seguro — padrão no mercado moderno.

Estudar TypeScript
7
Frameworks

⚛️ React ou Vue

Com a base sólida, parta para um framework de componentes. Escolha um e vá fundo — os conceitos se transferem entre eles.

React Vue.js
8
Back-end

🗄️ Backend & Banco de Dados

Construa o "outro lado": APIs com Node.js e armazenamento com SQL (MySQL ou PostgreSQL). Aqui você vira full stack de verdade.

Node.js & Express SQL & MySQL PostgreSQL
🏁
Projeto

🚀 Construa seu portfólio

Junte tudo em projetos reais: um site pessoal, um app que consome uma API, um CRUD full stack. Projeto vale mais que certificado — e é o que recrutadores olham.

Cheat Sheets Erros Comuns Glossário
💡
Dica de ouro Não tente aprender tudo de uma vez. Domine cada etapa com pequenos projetos antes de avançar. Constância vence intensidade.
