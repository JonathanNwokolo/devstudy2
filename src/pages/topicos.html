🔷 TypeScript

TypeScript Básico

JavaScript com superpoderes: tipagem estática para código mais seguro.

🎯 Por Que Usar TypeScript?

  • Erros em tempo de compilação: Pegue bugs antes de rodar
  • IntelliSense: Autocompletar inteligente no editor
  • Refatoração segura: Renomeie símbolos com confiança
  • Documentação automática: Tipos servem como docs
  • Escala melhor: Projetos grandes são mais gerenciáveis

📦 Tipos Básicos

// Primitivos
let nome: string = "João";
let idade: number = 25;
let ativo: boolean = true;

// Arrays
let numeros: number[] = [1, 2, 3];
let nomes: Array<string> = ["Ana", "Carlos"];

// Tuple (tamanho e tipos fixos)
let pessoa: [string, number] = ["Maria", 30];

// Enum
enum Status {
  Pendente,
  Aprovado,
  Rejeitado
}
let status: Status = Status.Aprovado;

// Any (evitar!)
let dados: any = "qualquer coisa";

// Unknown (mais seguro que any)
let valor: unknown = 4;
if (typeof valor === "number") {
  console.log(valor * 2);
}

// Void (função sem retorno)
function log(msg: string): void {
  console.log(msg);
}

// Never (nunca retorna)
function erro(msg: string): never {
  throw new Error(msg);
}

🏗️ Classes Tipadas

class Animal {
  // Modificadores de acesso
  public nome: string;
  private idade: number;
  protected especie: string;
  readonly id: number;

  constructor(nome: string, idade: number) {
    this.nome = nome;
    this.idade = idade;
    this.especie = "Desconhecida";
    this.id = Math.random();
  }

  // Método público
  falar(): string {
    return `${this.nome} faz um som`;
  }

  // Getter
  get idadeAnimal(): number {
    return this.idade;
  }
}

class Cachorro extends Animal {
  raca: string;

  constructor(nome: string, idade: number, raca: string) {
    super(nome, idade);
    this.especie = "Canino";
    this.raca = raca;
  }

  // Override
  falar(): string {
    return `${this.nome} late!`;
  }
}

const dog = new Cachorro("Rex", 3, "Labrador");
console.log(dog.falar()); // "Rex late!"

♿ A11y

Acessibilidade Web (WCAG)

Construa sites que todos possam usar, independente de suas capacidades.

📜 Princípios WCAG (POUR)

👁️ Perceptível

Informação deve ser apresentada de formas que usuários possam perceber.

  • Texto alternativo em imagens
  • Legendas em vídeos
  • Contraste de cores adequado

⌨️ Operável

Interface deve ser navegável por todos.

  • Navegação por teclado
  • Tempo suficiente para ler
  • Não causar convulsões

📖 Compreensível

Conteúdo deve ser entendível.

  • Texto legível
  • Comportamento previsível
  • Ajuda para erros

🔧 Robusto

Funcionar com tecnologias assistivas.

  • HTML válido
  • Nome, função, valor
  • Compatibilidade

🎨 Cores e Contraste

Requisitos WCAG:

  • Texto normal: contraste mínimo 4.5:1
  • Texto grande (18pt+): contraste mínimo 3:1
  • AAA (ideal): 7:1
✅ Bom: #333 em #fff (12.6:1)
❌ Ruim: #aaa em #fff (2.3:1)

Dicas:

  • Não use apenas cor para transmitir informação
  • Adicione ícones ou padrões junto com cores
  • Teste com simuladores de daltonismo

Ferramentas:

  • WebAIM Contrast Checker
  • Chrome DevTools (Lighthouse)
  • axe DevTools extension

✅ Checklist de Acessibilidade

  • □ Todas imagens têm alt text descritivo
  • □ Vídeos têm legendas/transcrição
  • □ Site navegável apenas por teclado
  • □ Foco visível em elementos interativos
  • □ Hierarquia de headings correta (h1→h2→h3)
  • □ Formulários com labels associados
  • □ Links descritivos (não "clique aqui")
  • □ Contraste de cores adequado
  • □ Texto redimensionável até 200%
  • □ Skip link para conteúdo principal
  • □ Funciona com zoom de 400%
  • □ Nenhum conteúdo pisca mais que 3x/s

⚡ JavaScript Performance

// Debounce - executa após parar de chamar
function debounce(fn, delay) {
  let timeout;
  return (...args) => {
    clearTimeout(timeout);
    timeout = setTimeout(() => fn(...args), delay);
  };
}

const handleSearch = debounce((query) => {
  fetch(`/api/search?q=${query}`);
}, 300);

// Throttle - executa no máximo 1x por intervalo
function throttle(fn, limit) {
  let inThrottle;
  return (...args) => {
    if (!inThrottle) {
      fn(...args);
      inThrottle = true;
      setTimeout(() => inThrottle = false, limit);
    }
  };
}

const handleScroll = throttle(() => {
  console.log('scroll');
}, 100);

// Intersection Observer (lazy load)
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.src = entry.target.dataset.src;
      observer.unobserve(entry.target);
    }
  });
});

document.querySelectorAll('img[data-src]')
  .forEach(img => observer.observe(img));

💾 Caching

// Service Worker para cache offline
// sw.js
const CACHE_NAME = 'v1';
const urlsToCache = ['/', '/style.css', '/app.js'];

self.addEventListener('install', (e) => {
  e.waitUntil(
    caches.open(CACHE_NAME)
      .then(cache => cache.addAll(urlsToCache))
  );
});

self.addEventListener('fetch', (e) => {
  e.respondWith(
    caches.match(e.request)
      .then(response => response || fetch(e.request))
  );
});

// Registrar no main.js
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js');
}

🔌 APIs

REST APIs

Como consumir e entender APIs RESTful.

📮 Métodos HTTP

GET Buscar dados GET /users
POST Criar recurso POST /users
PUT Atualizar (completo) PUT /users/1
PATCH Atualizar (parcial) PATCH /users/1
DELETE Remover DELETE /users/1

📊 Status Codes

2xx Sucesso

  • 200 OK
  • 201 Criado
  • 204 Sem conteúdo

3xx Redirecionamento

  • 301 Movido permanente
  • 302 Encontrado
  • 304 Não modificado

4xx Erro Cliente

  • 400 Bad Request
  • 401 Não autorizado
  • 403 Proibido
  • 404 Não encontrado
  • 422 Entidade inválida
  • 429 Muitas requisições

5xx Erro Servidor

  • 500 Erro interno
  • 502 Bad Gateway
  • 503 Indisponível

🌐 Consumindo APIs com Fetch

// GET - Buscar dados
const getUsers = async () => {
  const response = await fetch('https://api.exemplo.com/users');
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  return response.json();
};

// POST - Criar
const createUser = async (userData) => {
  const response = await fetch('https://api.exemplo.com/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer ' + token
    },
    body: JSON.stringify(userData)
  });
  return response.json();
};

// PUT - Atualizar
const updateUser = async (id, userData) => {
  const response = await fetch(`https://api.exemplo.com/users/${id}`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(userData)
  });
  return response.json();
};

// DELETE - Remover
const deleteUser = async (id) => {
  await fetch(`https://api.exemplo.com/users/${id}`, {
    method: 'DELETE'
  });
};

// Com tratamento de erros completo
const fetchWithErrorHandling = async (url, options = {}) => {
  try {
    const response = await fetch(url, options);
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.message || `HTTP ${response.status}`);
    }
    return response.json();
  } catch (error) {
    console.error('Fetch error:', error);
    throw error;
  }
};

🔤 Tipografia Fluida

/* Clamp - tamanho fluido com limites */
h1 {
  /* min: 2rem, preferred: 5vw, max: 4rem */
  font-size: clamp(2rem, 5vw, 4rem);
}

h2 {
  font-size: clamp(1.5rem, 4vw, 3rem);
}

p {
  font-size: clamp(1rem, 2.5vw, 1.25rem);
}

/* Spacing fluido */
.section {
  padding: clamp(2rem, 5vw, 6rem);
}

/* Combinando com variáveis CSS */
:root {
  --fs-xs: clamp(0.75rem, 0.7rem + 0.25vw, 0.875rem);
  --fs-sm: clamp(0.875rem, 0.8rem + 0.35vw, 1rem);
  --fs-base: clamp(1rem, 0.9rem + 0.5vw, 1.125rem);
  --fs-lg: clamp(1.125rem, 1rem + 0.6vw, 1.25rem);

  --fs-2xl: clamp(1.5rem, 1.3rem + 1vw, 2rem);
  --fs-3xl: clamp(2rem, 1.7rem + 1.5vw, 3rem);
}

🔲 Grid Auto-Responsivo

  grid-template-columns: repeat(
    auto-fit,

  );
  gap: clamp(1rem, 3vw, 2rem);
}

/* Cards responsivos sem media queries */
.card-grid {

  );

.layout {

  grid-template-columns:

  }

📐 Aspect Ratio

/* Aspect ratio nativo */
.video-container {
  aspect-ratio: 16 / 9;
  width: 100%;
}

.square {
  aspect-ratio: 1;  /* ou 1/1 */
}

.portrait {
  aspect-ratio: 3 / 4;
}

/* Com object-fit para imagens */
.image-card {
  aspect-ratio: 4 / 3;
}

.image-card img {
  width: 100%;
  height: 100%;
  object-fit: cover;        /* preenche */
  /* object-fit: contain;  mantém proporção */
  object-position: center;  /* posição do crop */
}

/* Fallback para browsers antigos */
.video-wrapper {
  position: relative;
  padding-bottom: 56.25%; /* 16:9 */
  height: 0;
}
.video-wrapper iframe {
  position: absolute;
  width: 100%;
  height: 100%;
}

🆕 Media Queries Modernas

/* Range syntax (novo!) */
@media (width >= 768px) {
  /* tablet e maior */
}

@media (400px <= width <= 800px) {
  /* entre 400 e 800px */
}

/* Preferências do usuário */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a1a;
    --text: #fff;
  }
}

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}

@media (prefers-contrast: high) {
  :root {
    --border-color: #000;
  }
}

/* Orientação */
@media (orientation: landscape) {
  .hero { height: 100vh; }
}

/* Hover capability */
@media (hover: hover) {
  .card:hover { transform: scale(1.05); }
}

@media (hover: none) {
  /* dispositivos touch */
  .card { /* sem efeito hover */ }
}
