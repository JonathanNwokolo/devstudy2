React

A Biblioteca UI Mais Popular

React é uma biblioteca JavaScript para construção de interfaces de usuário, focada em componentes reutilizáveis e programação declarativa.

🧩

Baseado em Componentes

Crie componentes encapsulados que gerenciam seu próprio estado e os combine para construir UIs complexas.

⚡

Virtual DOM

React utiliza um DOM virtual para otimizar atualizações, renderizando apenas o que mudou para máxima performance.

🔄

Reatividade

Com Hooks como useState e useEffect, React facilita o gerenciamento de estado e efeitos colaterais.

🌐

Ecossistema Rico

Ampla comunidade, ferramentas como Next.js, React Native, e milhares de bibliotecas compatíveis.

Domine os conceitos fundamentais para começar a desenvolver com React.

Componentes

Componentes são blocos de construção reutilizáveis. Podem ser funções ou classes que retornam elementos React. 

// Componente Funcional

Props são argumentos passados para componentes, permitindo a comunicação entre componentes pai e filho.

Estado (State) & Virtual DOM

O estado permite que componentes mantenham e atualizem dados que mudam ao longo do tempo com o Hook useState. O React usa o Virtual DOM para descobrir o que mudou e atualizar apenas aquele elemento na tela.

⚙️

useEffect - Efeitos Colaterais

O Hook useEffect permite executar código após a renderização, ideal para requisições, timers e manipulação do DOM. 

import { useEffect, useState } from 'react';

function Dados() {
  const [data, setData] = useState(null);
  
  useEffect(() => {
    fetch('/api/data')
      .then(res => res.json())
      .then(setData);
  }, []); // Array vazio: executa apenas uma vez
  
  return <div>{data}</div>;
}
Hooks

Hooks Essenciais do React

Hooks permitem usar estado e outras funcionalidades do React em componentes funcionais.

🪝 useState

Adiciona estado local a um componente funcional.

const [nome, setNome] = useState('');

⚙️ useEffect

Executa efeitos colaterais após renderização.

useEffect(() => {
  // código do efeito
}, [dependencia]);

Cria uma referência mutável que persiste entre renderizações.

const inputRef = useRef(null);

const valor = useMemo(() => 
  calcular(a, b), [a, b]);

⚡ useCallback

Memoriza funções para evitar recriações desnecessárias.

const handleClick = useCallback(() => {
  // função
}, [dep]);
Gerenciamento de Estado

Context API

Compartilhe dados entre componentes sem prop drilling. Ideal para temas, autenticação e configurações globais.

🎨

Criando um Context

Use createContext() para criar um contexto que pode ser compartilhado. 

import { createContext } from 'react';

// Criar o contexto
export const TemaContext = createContext(null);

// Provider Component
export function TemaProvider({children}) {
  const [tema, setTema] = useState('light');
  
  return (
    <TemaContext.Provider value={{tema, setTema}}>
      {children}
    </TemaContext.Provider>
  );
}
🔌

Consumindo Context

Use o hook useContext para acessar valores do contexto.

import { useContext } from 'react';
import { TemaContext } from './TemaContext';

function Botao() {
  const { tema, setTema } = useContext(TemaContext);
  
  return (
    <button className={tema}>
      Tema Atual: {tema}
    </button>
  );
}
🎯

Custom Hook para Context

Crie hooks customizados para facilitar o uso do contexto.

export function useTema() {
  const context = useContext(TemaContext);
  
  if (!context) {
    throw new Error('useTema deve ser usado dentro de TemaProvider');
  }
  
  return context;
}

// Uso simplificado
const { tema, setTema } = useTema();
Reutilização

Custom Hooks

Crie seus próprios hooks para extrair lógica reutilizável de componentes.

🔄 useFetch - Requisições HTTP

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  
  useEffect(() => {
    fetch(url)
      .then(res => res.json())
      .then(setData)
      .catch(setError)
      .finally(() => setLoading(false));
  }, [url]);
  
  return { data, loading, error };
}

// Uso
const { data, loading } = useFetch('/api/users');

💾 useLocalStorage

function useLocalStorage(key, defaultValue) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key);
    return saved ? JSON.parse(saved) : defaultValue;
  });
  
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);
  
  return [value, setValue];
}

// Uso
const [nome, setNome] = useLocalStorage('nome', '');

🖱️ useDebounce

function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value);
  
  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);
    
    return () => clearTimeout(timer);
  }, [value, delay]);
  
  return debouncedValue;
}

📐 useWindowSize

function useWindowSize() {
  const [size, setSize] = useState({
    width: window.innerWidth,
    height: window.innerHeight
  });
  
  useEffect(() => {
    const handleResize = () => {
      setSize({
        width: window.innerWidth,
        height: window.innerHeight
      });
    };
    
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);
  
  return size;
}

Componentes Controlados

function Formulario() {
  const [nome, setNome] = useState('');
  const [email, setEmail] = useState('');
  
  const handleSubmit = (e) => {
    e.preventDefault();
    console.log({ nome, email });
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input
        value={nome}
        onChange={(e) => setNome(e.target.value)}
      />
      <button type="submit">Enviar</button>
    </form>
  );
}
✅

Validação de Formulário

Implemente validação customizada para seus formulários.

function FormularioValidado() {
  const [email, setEmail] = useState('');
  const [erro, setErro] = useState('');
  
  const validarEmail = (email) => {
    const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return regex.test(email);
  };
  
  const handleSubmit = (e) => {
    e.preventDefault();
    
    if (!validarEmail(email)) {
      setErro('Email inválido');
      return;
    }
    
    setErro('');
    // Enviar formulário
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input value={email} onChange={(e) => setEmail(e.target.value)} />
      {erro && <span>{erro}</span>}
      <button>Enviar</button>
    </form>
  );
}
🎛️

Múltiplos Inputs

Gerencie vários campos com um único estado.

function FormularioCompleto() {
  const [formData, setFormData] = useState({
    nome: '',
    email: '',
    idade: ''
  });
  
  const handleChange = (e) => {
    const { name, value } = e.target;
    setFormData(prev => ({
      ...prev,
      [name]: value
    }));
  };
  
  return (
    <form>
      <input name="nome" value={formData.nome} onChange={handleChange} />
      <input name="email" value={formData.email} onChange={handleChange} />
      <input name="idade" value={formData.idade} onChange={handleChange} />
    </form>
  );
}
Otimização

Otimização de Performance

Técnicas para melhorar o desempenho de aplicações React.

⚡ React.memo

Evita re-renderizações desnecessárias de componentes.

const ListaItem = React.memo(({item}) => {
  console.log('Renderizando item');
  return <li>{item.nome}</li>;
});

// Com comparação customizada
const ListaItemCustom = React.memo(
  Item,
  (prevProps, nextProps) => {
    return prevProps.id === nextProps.id;
  }
);

🧮 useMemo para Cálculos

Memoriza resultados de cálculos custosos.

function Lista({itens, filtro}) {
  const itensFiltrados = useMemo(() => {
    console.log('Calculando filtro...');
    return itens.filter(item => 
      item.includes(filtro)
    );
  }, [itens, filtro]); // Só recalcula se itens ou filtro mudarem
  
  return (
    <ul>
      {itensFiltrados.map(item => <li>{item}</li>)}
    </ul>
  );
}

⚡ useCallback para Funções

Evita recriação de funções em cada renderização.

function TodoList() {
  const [todos, setTodos] = useState([]);
  
  // Função memorizada
  const addTodo = useCallback((text) => {
    setTodos(prev => [...prev, text]);
  }, []); // Array vazio = função nunca muda
  
  return <TodoForm onAdd={addTodo} />;
}

Boas Práticas React

Convenções e padrões recomendados pela comunidade React.

📁

Estrutura de Pastas

Organize por features: cada funcionalidade em sua própria pasta com componentes, hooks e testes relacionados juntos.

🎨

Nomenclatura

Componentes em PascalCase, hooks com prefixo 'use', constantes em UPPER_CASE, variáveis e funções em camelCase. 

// ✅ Bom
function UserProfile() {}
const useUser = () => {}
const API_URL = '...';

// ❌ Evite
function user_profile() {}
const getUser = () => {}
🔑

Keys em Listas

Sempre use keys únicas e estáveis em listas. Evite usar índices como keys se a ordem puder mudar. 

// ✅ Bom
{items.map(item => (
  <Item key={item.id} />
))}

// ❌ Evite
{items.map((item, index) => (
  <Item key={index} />
))}
🧩

Componentes Pequenos

Mantenha componentes focados em uma única responsabilidade. Divida componentes grandes em menores. 

// Ao invés de um componente grande
function Dashboard() {} // 500 linhas

// Divida em componentes menores
function Dashboard() {
  return (
    <>
      <Header />
      <Sidebar />
      <MainContent />
      <Footer />
    </>
  );
}
⚠️

Tratamento de Erros

Use Error Boundaries para capturar erros em componentes e evitar que toda a aplicação quebre. 

class ErrorBoundary extends React.Component {
  componentDidCatch(error) {
    console.error(error);
  }
  
  render() {
    if (this.state.hasError) {
      return <h1>Algo deu errado</h1>;
    }
    return this.props.children;
  }
}

function User(props) {
