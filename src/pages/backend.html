🟢 O outro lado da aplicação

Backend com Node.js

O back-end é a parte que o usuário não vê: a lógica, o servidor e o banco de dados. Com Node.js você usa o mesmo JavaScript do front para construir APIs.

🟢

O que é Node.js?

É um ambiente que roda JavaScript fora do navegador — no servidor, no seu computador. Com ele você cria APIs, lê arquivos, acessa bancos de dados e muito mais.

▶️
Rodando seu primeiro arquivo Salve um app.js e rode no terminal com node app.js. Precisa do terminal e npm instalados.

🖥️ Um servidor HTTP do zero

Sem bibliotecas, só com o módulo nativo http.

JavaScript (Node) 
const http = require("http");

const servidor = http.createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ mensagem: "Olá do servidor!" }));
});

servidor.listen(3000, () => {
  console.log("Rodando em http://localhost:3000");
});

🚂 API REST com Express

Express é o framework mais popular para Node. Instale com npm install express.

JavaScript (Node) 
const express = require("express");
const app = express();
app.use(express.json()); // entende JSON no corpo das requisições

let tarefas = [{ id: 1, texto: "Estudar Node" }];

// GET — listar
app.get("/tarefas", (req, res) => res.json(tarefas));

// POST — criar
app.post("/tarefas", (req, res) => {
  const nova = { id: Date.now(), texto: req.body.texto };
  tarefas.push(nova);
  res.status(201).json(nova);
});

app.listen(3000, () => console.log("API no ar! 🚀"));
🔗
Conecte os pontos Essa API responde aos verbos HTTP (GET/POST) e pode ser consumida pelo fetch no front-end. É o ciclo completo!

🔀 CRUD completo: rotas com parâmetro

O :id na rota vira req.params.id. Assim você lê, atualiza ou apaga um item específico.

JavaScript (Node) 
// GET um item — /tarefas/3
app.get("/tarefas/:id", (req, res) => {
  const tarefa = tarefas.find(t => t.id == req.params.id);
  if (!tarefa) return res.status(404).json({ erro: "Não encontrada" });
  res.json(tarefa);
});

// PUT — atualizar
app.put("/tarefas/:id", (req, res) => {
  const tarefa = tarefas.find(t => t.id == req.params.id);
  if (!tarefa) return res.status(404).json({ erro: "Não encontrada" });
  tarefa.texto = req.body.texto;
  res.json(tarefa);
});

// DELETE — remover
app.delete("/tarefas/:id", (req, res) => {
  tarefas = tarefas.filter(t => t.id != req.params.id);
  res.status(204).end(); // 204 = sucesso, sem corpo
});
📡
O que é REST? É um estilo de API onde cada recurso (ex: tarefas) tem uma URL e você usa os verbos HTTP para agir sobre ele: GET (ler), POST (criar), PUT/PATCH (atualizar), DELETE (apagar).

JavaScript (Node) 
// Roda em TODA requisição (log simples)
app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next(); // sem isso, a requisição "trava" aqui
});

// Middleware só em uma rota (ex: checar token)
function autenticar(req, res, next) {
  if (!req.headers.authorization)
    return res.status(401).json({ erro: "Sem token" });
  next();
}

app.get("/perfil", autenticar, (req, res) => {
  res.json({ nome: "Ana" });
});

⏳ Rotas assíncronas (banco de dados)

Acessar banco demora, então usamos async/await com try/catch para tratar erros.

JavaScript (Node) 
app.get("/usuarios", async (req, res) => {
  try {
    const usuarios = await db.query("SELECT * FROM usuarios");
    res.json(usuarios);
  } catch (erro) {
    res.status(500).json({ erro: "Falha no banco" });
  }
});
🔢
Status codes que você vai usar 200 OK · 201 Criado · 204 Sem conteúdo · 400 Erro do cliente · 401 Não autenticado · 404 Não encontrado · 500 Erro do servidor. Veja todos em HTTP.
