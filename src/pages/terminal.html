⌨️ A base de todo dev

Terminal & npm

O terminal assusta no começo, mas é uma das ferramentas mais poderosas que você vai usar todo dia. Aqui estão os comandos essenciais para se virar — sem decoreba.

💬

O que é o terminal (CLI)?

É uma interface de texto onde você digita comandos em vez de clicar. No Windows há o PowerShell e o CMD; no Mac/Linux, o Bash/Zsh. A maioria dos comandos de arquivos é parecida.

🧭 Navegar entre pastas

bash 
pwd          # mostra a pasta atual (onde estou?)
ls           # lista arquivos e pastas (dir no CMD)
cd projetos  # entra na pasta 'projetos'
cd ..        # volta uma pasta
cd ~         # vai para a pasta do usuário (home)
clear        # limpa a tela (cls no CMD)

📁 Criar e gerenciar arquivos

bash 
mkdir meu-site        # cria uma pasta
touch index.html      # cria um arquivo vazio (Linux/Mac)
cp a.txt b.txt        # copia
mv a.txt pasta/       # move (ou renomeia)
rm arquivo.txt        # apaga arquivo
rm -r pasta           # apaga pasta e tudo dentro (cuidado!)
⚠️
Cuidado com o rm rm -r apaga sem ir para a lixeira. Confira sempre a pasta antes de apertar Enter.

📦 npm — o gerenciador de pacotes

O npm vem com o Node.js. Ele instala bibliotecas e roda os scripts do seu projeto.

bash 
npm init -y               # cria o package.json
npm install axios         # instala um pacote (vai p/ dependencies)
npm install -D vite       # instala como dependência de DEV
npm install               # instala tudo do package.json
npm uninstall axios       # remove um pacote
npm run dev               # roda o script "dev"

📄 O package.json

É a "identidade" do projeto: nome, dependências e scripts.

json 
{
  "name": "meu-projeto",
  "version": "1.0.0",
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  },
  "dependencies": {
    "axios": "^1.6.0"
  }
}
📌
node_modules e .gitignore A pasta node_modules é enorme e nunca vai pro Git. Coloque-a no .gitignore — quem clonar o projeto roda npm install para recriá-la.

🚀 npx & versionamento semântico

npx roda um pacote sem instalar de forma permanente — ótimo para criar projetos.

bash 
npx create-vite@latest meu-app   # cria projeto sem instalar nada global
npx prettier --write .           # roda uma ferramenta pontualmente
VersãoO que aceita atualizar
1.6.0Exatamente essa versão
^1.6.0Correções e novidades menores (1.x.x)
~1.6.0Só correções (1.6.x)
🔢
SemVer: MAIOR.MENOR.CORREÇÃO 2.5.1 → muda a 1ª quebra compatibilidade, a 2ª adiciona recurso, a 3ª corrige bug. Por isso o ^ é seguro: não pula a versão MAIOR.

🌱 Variáveis de ambiente & encadeamento

Variáveis guardam config/segredos fora do código; operadores combinam comandos.

bash 
echo $HOME              # lê uma variável (no Windows: $env:HOME)
export API_KEY=abc123   # define uma variável na sessão

npm run build && npm start   # roda o 2º só se o 1º der certo
ls | grep ".js"              # "pipe": saída de um vira entrada do outro
📄
Arquivo .env Na prática, segredos vão num arquivo .env (que entra no .gitignore) e o projeto os lê em process.env.
