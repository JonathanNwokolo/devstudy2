🗄️ A língua dos bancos de dados

SQL & MySQL

SQL é a linguagem que você usa para conversar com bancos de dados relacionais. Aprenda uma vez e use no MySQL, PostgreSQL, SQLite e SQL Server — mudam só alguns detalhes.

🗄️

O que é SQL?

SQL (Structured Query Language) é a linguagem padrão para criar, consultar e alterar dados em bancos relacionais. O banco guarda os dados em tabelas (colunas + linhas) e o SQL é o que você escreve para pedir ou modificar esses dados.

🐬
SQL x MySQL x PostgreSQL SQL é a linguagem. MySQL e PostgreSQL são programas (sistemas gerenciadores de banco de dados) que entendem SQL. O MySQL é muito popular em sites e WordPress; o PostgreSQL é mais completo e rigoroso. Veja a página de PostgreSQL.

🏗️ CREATE TABLE

MySQL 
CREATE TABLE usuarios (
  id INT AUTO_INCREMENT PRIMARY KEY,   -- MySQL: AUTO_INCREMENT
  nome VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE,
  ativo BOOLEAN DEFAULT TRUE,
  criado_em DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE pedidos (
  id INT AUTO_INCREMENT PRIMARY KEY,
  total DECIMAL(10,2),
  usuario_id INT,
  FOREIGN KEY (usuario_id) REFERENCES usuarios(id)
);

✏️ INSERT, SELECT, UPDATE & DELETE

SQL 
-- Criar
INSERT INTO usuarios (nome, email) VALUES ('Ana', 'ana@email.com');

-- Ler
SELECT nome, email FROM usuarios WHERE ativo = TRUE ORDER BY nome LIMIT 10;

-- Atualizar (SEMPRE com WHERE!)
UPDATE usuarios SET email = 'novo@email.com' WHERE id = 1;

-- Apagar (SEMPRE com WHERE!)
DELETE FROM usuarios WHERE id = 1;
⚠️
O erro clássico UPDATE ou DELETE sem WHERE afeta todas as linhas. Teste primeiro com um SELECT usando o mesmo WHERE.

SQL 
-- Só quem tem pedido
SELECT u.nome, p.total
FROM usuarios u
INNER JOIN pedidos p ON p.usuario_id = u.id;

-- Todos os usuários, com ou sem pedido
SELECT u.nome, p.total
FROM usuarios u
LEFT JOIN pedidos p ON p.usuario_id = u.id;

INNER JOIN traz só o que casa nas duas tabelas; LEFT JOIN traz tudo da esquerda e NULL onde não há par. Mais detalhes na página de PostgreSQL.

📊 Funções de agregação & GROUP BY

SQL 
SELECT usuario_id,
       COUNT(*)   AS qtd_pedidos,
       SUM(total) AS gasto_total,
       AVG(total) AS ticket_medio
FROM pedidos
GROUP BY usuario_id
HAVING SUM(total) > 100
ORDER BY gasto_total DESC;
🧠
Ordem de escrita SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT.

🪆 Subconsultas

Uma consulta dentro de outra — útil quando a resposta de uma depende do resultado da outra.

SQL 
-- Usuários que fizeram ao menos um pedido
SELECT nome FROM usuarios
WHERE id IN (SELECT usuario_id FROM pedidos);

-- Pedidos acima da média
SELECT * FROM pedidos
WHERE total > (SELECT AVG(total) FROM pedidos);

🛠️ ALTER, DROP & TRUNCATE

SQL 
-- Adicionar coluna
ALTER TABLE usuarios ADD COLUMN telefone VARCHAR(20);

-- Remover coluna
ALTER TABLE usuarios DROP COLUMN telefone;

-- Esvaziar a tabela (mantém a estrutura)
TRUNCATE TABLE pedidos;

-- Apagar a tabela inteira
DROP TABLE pedidos;
🚨
Sem volta DROP e TRUNCATE não pedem confirmação e não passam pelo WHERE. Faça backup antes de rodar em produção.

⚡ Índices — deixando consultas rápidas

Um índice funciona como o índice de um livro: o banco acha a linha sem ler a tabela inteira.

SQL 
CREATE INDEX idx_usuarios_email ON usuarios(email);

-- Ver como o banco executa a consulta
EXPLAIN SELECT * FROM usuarios WHERE email = 'ana@email.com';
💡
Onde indexar Colunas usadas em WHERE, JOIN e ORDER BY. Índices demais deixam INSERT e UPDATE mais lentos.

🔒 Transações

Agrupam vários comandos: ou todos funcionam, ou nenhum. Clássico exemplo: transferência bancária.

SQL 
START TRANSACTION;   -- no PostgreSQL também vale BEGIN

UPDATE contas SET saldo = saldo - 100 WHERE id = 1;
UPDATE contas SET saldo = saldo + 100 WHERE id = 2;

COMMIT;      -- confirma tudo
-- ROLLBACK; -- ou desfaz tudo se algo deu errado

🛡️
SQL Injection Nunca monte SQL concatenando texto do usuário: "... WHERE email = '" + email + "'". Use sempre consultas parametrizadas (? no MySQL, $1 no PostgreSQL) ou um ORM como Prisma.

🟢 Usando no Node.js

JavaScript 
// MySQL com mysql2
const mysql = require('mysql2/promise');
const db = await mysql.createConnection({
  host: 'localhost', user: 'root', database: 'loja',
});

// O "?" é preenchido com segurança — evita SQL Injection
const [linhas] = await db.execute(
  'SELECT * FROM usuarios WHERE email = ?',
  [email]
);
