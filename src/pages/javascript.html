⚡ Ordem de Precedência

A ordem em que os operadores são avaliados (do maior para o menor):

Precedência Operador Descrição Exemplo
1 (mais alta) ( ) Agrupamento (2 + 3) * 4 → 20
2 ++ -- Incremento/Decremento x++, --y
3 ! ~ + - Negação, NOT, Unário !true, -5
4 ** Exponenciação 2 ** 3 → 8
5 * / % Multiplicação, Divisão, Módulo 10 % 3 → 1
6 + - Adição, Subtração 5 + 3 → 8
7 < <= > >= Comparação 5 > 3 → true
8 == != === !== Igualdade 5 === 5 → true
9 && AND lógico true && false → false
10 || OR lógico true || false → true
11 ?? Nullish coalescing null ?? 5 → 5
12 ? : Ternário (condicional) x > 5 ? "sim" : "não"
13 (mais baixa) = += -= *= /= Atribuição x = 10, y += 5
Operadores de Atribuição Compostos 
let num = 10;

num += 5;   // num = num + 5  → 15
num -= 3;   // num = num - 3  → 12
num *= 2;   // num = num * 2  → 24
num /= 4;   // num = num / 4  → 6
num %= 4;   // num = num % 4  → 2
num **= 3;  // num = num ** 3 → 8

// Operadores lógicos com atribuição (ES2021)
let valor = 0;
valor ||= 10;  // Se falsy, atribui 10 → valor = 10
valor &&= 5;   // Se truthy, atribui 5 → valor = 5

let data = null;
data ??= "Padrão"; // Se null/undefined, atribui → data = "Padrão"

Operadores Bit a Bit (Bitwise) 
// Operadores bit a bit trabalham com representação binária

// AND (&) - retorna 1 se ambos bits são 1
console.log(5 & 3);  // 1 (101 & 011 = 001)

// OR (|) - retorna 1 se pelo menos um bit é 1
console.log(5 | 3);  // 7 (101 | 011 = 111)

// XOR (^) - retorna 1 se os bits são diferentes
console.log(5 ^ 3);  // 6 (101 ^ 011 = 110)

// NOT (~) - inverte todos os bits
console.log(~5);     // -6 (~101 = ...11111010)

// Deslocamento à esquerda (<<) - multiplica por 2^n
console.log(5 << 1); // 10 (101 << 1 = 1010)
console.log(5 << 2); // 20 (101 << 2 = 10100)

// Deslocamento à direita (>>) - divide por 2^n
console.log(20 >> 1); // 10 (10100 >> 1 = 1010)
console.log(20 >> 2); // 5  (10100 >> 2 = 101)

// Uso prático: verificar permissões (flags)
const READ = 1;    // 001
const WRITE = 2;   // 010
const EXECUTE = 4; // 100

let permissoes = READ | WRITE; // 011 (pode ler e escrever)
console.log(permissoes & READ);  // 1 (tem permissão de leitura)
console.log(permissoes & EXECUTE); // 0 (não tem permissão de execução)
Exemplos de Precedência 
// Sem parênteses - segue a precedência natural
let resultado1 = 2 + 3 * 4;     // 14 (não 20!) - multiplicação primeiro
let resultado2 = 10 / 2 + 3;    // 8 (5 + 3) - divisão primeiro
let resultado3 = 5 + 3 > 4 * 2; // false (8 > 8) - aritmética antes de comparação

// Com parênteses - altera a ordem
let resultado4 = (2 + 3) * 4;   // 20 - parênteses têm prioridade máxima
let resultado5 = 10 / (2 + 3);  // 2 (10 / 5)

// Múltiplos operadores
let x = 5;
let y = 10;
let z = x++ + ++y;    // 16 (5 + 11) - incremento pré-fixo executa primeiro
console.log(x, y, z); // 6, 11, 16

// AND tem precedência sobre OR
let logico1 = true || false && false; // true (|| executa depois do &&)
let logico2 = (true || false) && false; // false (parênteses mudam a ordem)
💡
Dica: Quando em dúvida, use parênteses ( )! Eles tornam o código mais legível e deixam a intenção clara, mesmo que não sejam necessários.
== vs === (Importante!) 
// == compara apenas o VALOR (faz conversão de tipo)
console.log(5 == "5");    // true ⚠️
console.log(0 == false);  // true ⚠️
console.log(null == undefined); // true ⚠️

// === compara VALOR e TIPO (recomendado!)

console.log(0 === false); // false ✅

🔄 Switch Case

Quando usar switch 
const diaSemana = 3;
let nomeDia;

switch (diaSemana) {       // switch compara diaSemana com cada case
    case 1:
        nomeDia = "Segunda-feira";
        break;             // break impede de executar os cases seguintes
    case 2:
        nomeDia = "Terça-feira";
        break;
    case 3:                // ← diaSemana === 3, este case será executado
        nomeDia = "Quarta-feira";
        break;
    case 4:
        nomeDia = "Quinta-feira";
        break;
    case 5:
        nomeDia = "Sexta-feira";
        break;
    case 6:
    case 7:                // dois cases sem break = ambos executam o mesmo bloco
        nomeDia = "Fim de semana! 🎉";
        break;
    default:               // executado se nenhum case casar
        nomeDia = "Dia inválido";
}

console.log(nomeDia); // "Quarta-feira"

✨ Spread & Rest (...)

O mesmo ... "espalha" valores ou "junta" vários em um.

JavaScript 
// SPREAD: copiar/combinar (sem alterar o original)
const arr = [1, 2, 3];
const copia = [...arr, 4];        // [1, 2, 3, 4]

const base = { nome: "Ana", idade: 30 };

// REST: juntar o "resto" em um array
function somar(...numeros) {
    return numeros.reduce((a, b) => a + b, 0);
}
somar(1, 2, 3, 4); // 10

🔄 Fetch API - Consumindo APIs

Buscando dados de uma API 
// Usando Promises (.then)
fetch("https://api.exemplo.com/dados")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error("Erro:", error);
    });

// Usando async/await (mais moderno e legível)
async function buscarDados() {
    try {
        const response = await fetch("https://api.exemplo.com/dados");
        const data = await response.json();
        console.log(data);
        return data;
    } catch (error) {
        console.error("Erro:", error);
    }
}

// Exemplo prático: buscar usuários do GitHub
async function buscarUsuario(username) {
    try {
        const response = await fetch(`https://api.github.com/users/${username}`);
        
        if (!response.ok) {
            throw new Error("Usuário não encontrado");
        }
        
        const usuario = await response.json();
        console.log(`Nome: ${usuario.name}`);
        console.log(`Repositórios: ${usuario.public_repos}`);
        return usuario;
    } catch (error) {
        console.error(error.message);
    }
}

buscarUsuario("octocat");
📦 Módulos

Módulos ES6 (import / export)

Em vez de um arquivo gigante, divida o código em arquivos que exportam e importam funções entre si.

📤 Exportar e importar

matematica.js 
// Export nomeado (vários por arquivo)
export function somar(a, b) { return a + b; }
export const PI = 3.14;

// Export default (um por arquivo)
export default function multiplicar(a, b) { return a * b; }
app.js 
// Nomeados vêm entre chaves; o default, sem chaves
import multiplicar, { somar, PI } from "./matematica.js";

somar(2, 3);       // 5
multiplicar(2, 3); // 6

// Importar tudo num objeto
import * as mat from "./matematica.js";
mat.somar(1, 1);
🌐
No navegador Para usar import no HTML, marque o script como módulo: <script type="module" src="app.js"></script>.
🔗
É a base de tudo React, Vue, Node — todos usam módulos. Dominar import/export é pré-requisito para qualquer framework.
💡 Dicas

Boas Práticas

01

Use const por padrão

Declare variáveis com const. Use let apenas quando precisar reatribuir.

02

Sempre use ===

Comparação estrita evita bugs. === compara valor e tipo.

03

Nomes descritivos

Use usuarioAtivo em vez de ua. Código é lido mais do que escrito.

04

Funções pequenas

Cada função deve fazer uma coisa. Se tem mais de 20 linhas, considere dividir.

05

Evite var

var tem escopo de função e hoisting. let e const são mais seguros.

06

Console é seu amigo

Use console.log(), console.table(), console.dir() para debugar.
