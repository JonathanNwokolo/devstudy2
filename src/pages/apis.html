APIs, Fetch & Async

Quase todo app moderno busca dados de um servidor: clima, produtos, usuários... Aqui você aprende a consumir APIs com fetch, entender JSON e dominar o código assíncrono.

🔌

O que é uma API?

É um "garçom" entre sistemas: seu código faz um pedido a uma URL (o endpoint) e recebe uma resposta — normalmente em JSON. Veja os métodos e status HTTP para entender o que rola por baixo.

📥 Buscar dados (GET) com fetch

JavaScript 
fetch("https://api.exemplo.com/usuarios")
  .then((resposta) => resposta.json()) // converte o corpo em objeto JS
  .then((dados) => console.log(dados))
  .catch((erro) => console.error("Falhou:", erro));
🧩
JSON É o formato de troca de dados na web — texto no estilo { "nome": "Ana" }. resposta.json() transforma esse texto em objeto JavaScript.

⏳ async / await (mais legível)

Mesma coisa do GET acima, mas escrito como se fosse código "normal", de cima para baixo.

JavaScript 
async function carregarUsuarios() {
  try {
    const resposta = await fetch("https://api.exemplo.com/usuarios");

    if (!resposta.ok) {
      throw new Error("Erro HTTP: " + resposta.status);
    }

    const dados = await resposta.json();
    console.log(dados);
  } catch (erro) {
    console.error("Algo deu errado:", erro);
  }
}

carregarUsuarios();
⚠️
fetch não rejeita em erro 404/500! Ele só falha em erro de rede. Sempre cheque resposta.ok ou resposta.status.

📤 Enviar dados (POST)

JavaScript 
async function criarUsuario() {
  const resposta = await fetch("https://api.exemplo.com/usuarios", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ nome: "Ana", idade: 30 }),
  });
  const novo = await resposta.json();
  console.log("Criado:", novo);
}

♻️ Atualizar (PUT) e apagar (DELETE)

Mesmo padrão do POST, mudando só o method.

JavaScript 
// Atualizar o usuário 1
await fetch("https://api.exemplo.com/usuarios/1", {
  method: "PUT",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ nome: "Ana Maria" }),
});

// Apagar o usuário 1
await fetch("https://api.exemplo.com/usuarios/1", {
  method: "DELETE",
});

🔑 Headers & autenticação

APIs privadas pedem um token no cabeçalho Authorization.

JavaScript 
const resposta = await fetch("https://api.exemplo.com/perfil", {
  headers: {
    "Authorization": `Bearer ${meuToken}`,
    "Content-Type": "application/json",
  },
});
🔒
Nunca exponha tokens secretos no front-end Chaves sensíveis ficam no back-end. No navegador, qualquer um vê o código — use só tokens públicos ou de sessão do usuário.

🔎 Query params (filtros na URL)

Aquele ?chave=valor no fim da URL é como APIs recebem filtros, busca e paginação.

JavaScript 
// .../produtos?categoria=livros&pagina=2
const params = new URLSearchParams({ categoria: "livros", pagina: 2 });
const resposta = await fetch(`https://api.exemplo.com/produtos?${params}`);

⚡ Várias requisições ao mesmo tempo

Promise.all dispara tudo em paralelo e espera todas — muito mais rápido que uma de cada vez.

JavaScript 
const [usuarios, produtos] = await Promise.all([
  fetch("/api/usuarios").then(r => r.json()),
  fetch("/api/produtos").then(r => r.json()),
]);
// chega quando AS DUAS terminarem

🤝 Promises: os 3 estados

Uma Promise representa um valor que chega no futuro.

EstadoSignificado
pendingAinda esperando o resultado
fulfilledDeu certo → .then() / await
rejectedDeu erro → .catch() / try/catch
🧪
Pratique de graça Use APIs públicas como jsonplaceholder.typicode.com (dados fake) ou viacep.com.br (CEP) para treinar fetch sem precisar de servidor próprio.
