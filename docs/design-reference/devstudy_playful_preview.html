# DevStudy Playground — Referência visual aprovada Este pacote contém o protótipo *conceitual* aprovado visualmente pelo usuário. ## Arquivos - `devstudy_playful_preview.html` — protótipo navegável com homepage e página de conteúdo; CSS/JS incluídos no próprio arquivo; depende de fontes Google e GSAP via CDN para parte do efeito visual. - `devstudy_playful_home.png` — captura integral desktop da homepage (1443 × 2181). - `devstudy_playful_docs.png` — captura integral desktop da página de conteúdo (1440 × 1785). - `devstudy_playful_mobile.png` — captura integral mobile (392 × 2789). - `devstudy_playful_home_preview.png` — recorte/visão inicial da homepage. - `devstudy_playful_docs_preview.png` — recorte/visão inicial da página de conteúdo. ## Como usar na revisão 1. Trate estas capturas e o HTML como **referências visuais**, não como implementação pronta nem como prova de que as funções do produto funcionam. 2. Compare homepage e página de JavaScript da implementação real, em 1440, 768 e 390 px (a captura de referência mobile foi feita em 392 px). 3. Faça uma matriz de divergências com severidade, evidência e caminho de arquivo/componente. 4. Priorize: identidade/tipografia, composição hero, cena de código em CSS 3D, cards, sidebar, blocos de código, espaçamento e adaptação mobile. 5. Preserve conteúdos, links, busca, favoritos, editores, simuladores, tema, acessibilidade e comportamento sem GSAP. 6. Não copie os elementos de demonstração do HTML (por exemplo busca simulada ou favoritos ilustrativos) sobre as funções reais do repositório. 7. O protótipo foi aprovado como **direção artística**, não exigência de fidelidade pixel-perfect. Meça similaridade de estrutura, hierarquia, linguagem visual e comportamento; reporte diferenças aceitáveis. 8. Não faça commit, push ou deploy sem autorização.
