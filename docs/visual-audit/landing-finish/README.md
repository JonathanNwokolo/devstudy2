# Aberturas editoriais — comparação visual

As imagens `*-before-user.png` são as capturas anotadas enviadas pelo usuário. As imagens `*-after-1440.png` são do build local após alinhar as aberturas à página JavaScript. A comparação é de direção visual, pois as capturas originais têm larguras e posições de rolagem diferentes.

| Página | Antes | Depois |
| --- | --- | --- |
| HTML na home | [captura original](html-before-user.png) | [abertura editorial](html-after-1440.png) |
| CSS | [captura original](css-before-user.png) | [página CSS](css-after-1440.png), [seção da home](home-css-after-1440.png) |
| Git | [captura original](git-before-user.png) | [abertura editorial](git-after-1440.png) |

HTTP, React e Vue também foram inspecionados em [1440 px](http-after-1440.png), [1440 px](react-after-1440.png) e [1440 px](vue-after-1440.png), respectivamente. Há ainda capturas de [CSS em 768 px](css-after-768.png), [CSS em 390 px](css-after-390.png), [React em 390 px](react-after-390.png), [React escuro em 390 px](react-after-dark-390.png) e [Git escuro em 1440 px](git-after-dark-1440.png). A referência JavaScript aprovada permanece em `../screenshots/after/javascript-1440.png`.

O padrão antigo usava grandes fundos em gradiente, títulos centralizados e ilustrações decorativas. O resultado usa badge compacto, título escuro à esquerda, descrição legível, estatísticas discretas e superfícies Playground. Cards, conteúdo didático, navegação e efeitos do restante da página foram preservados.
