✳ Fundamentos⌘ Exemplos práticos

O que é JavaScript? ✳

JavaScript é uma linguagem de programação usada para criar experiências interativas na web. Ela permite responder às ações do usuário, atualizar conteúdos e modificar elementos de uma página.

Ao lado do HTML e CSS, ela forma uma das bases do desenvolvimento front-end.

Variáveis e constantes

Em JavaScript moderno, usamos const para valores que não serão reatribuídos e let quando um valor precisa mudar.

const

Declara uma variável cujo identificador não pode ser reatribuído.

let

Declara uma variável cujo valor pode ser reatribuído.

Olha isso na prática. ↘

O mesmo conceito pode ser testado diretamente no editor já existente do projeto.

● ● ●   exemplo.js
const nome = "DevStudy";
let progresso = 1;

progresso += 1;
console.log(nome, progresso);
✦ DICA RÁPIDA

Comece com const e use let apenas quando precisar reatribuir um valor.
